# Море как актив — Малый Утриш

Адаптивный инвестиционный сайт-презентация и Digital Data Room действующей мидийно-устричной фермы.

## Запуск в разработке

```bash
npm install
npm run db:push
npm run dev
```

Сервер и интерфейс доступны на `http://localhost:3000`.

## Production

```bash
npm run check
npm run lint
npm run build
npm start
```

Production-сборка создаёт серверный пакет `dist/boot.js` и клиентские файлы в `dist/public/`. Для работы формы процессу нужна переменная `DATABASE_URL` из серверного окружения.

## Состав

- React, TypeScript, Vite, Hono, tRPC, Drizzle ORM и MySQL.
- Полный интерактивный реестр имущества из `src/data/inventory.ts`: 226 строк, поиск, фильтры, пагинация и экспорт текущей выборки в CSV.
- Структура оценки, три РВУ, коллекторы, интерактивная схема береговой базы, сценарный расчёт простой окупаемости и 11 направлений роста.
- Форма «Запросить исходную ведомость» сохраняет обращения в таблицу `source_requests`. Предусмотрены серверная валидация, обязательное согласие, honeypot и базовое ограничение частоты запросов.
- Автоматические уведомления в Telegram, на почту и во внешние webhook не подключены и интерфейсом не обещаются.
- Исходная ведомость также доступна в разделе методики как `public/source-inventory-2026.xlsx`.
- Видео и изображения находятся в `public/media/`. Подводный ролик и его реверсивная версия загружаются рядом с соответствующим разделом и работают в режиме плавного прямого/обратного цикла.
- PWA-манифест, иконки и Service Worker с сетевой загрузкой HTML без устаревшего cache-first.
- Поддержка клавиатуры, возврата фокуса из диалога, `prefers-reduced-motion`, печати и мобильных safe-area.

## Данные и шрифты

Все финансовые значения и описания актива получены из предоставленной владельцем таблицы 2026 года. Оценки владельца отделены от независимо проверяемых сведений. Расчёт окупаемости показывает пользовательские допущения и не является прогнозом или инвестиционной рекомендацией. Пустые цены не заменяются нулями.

Onest Variable используется для заголовков и акцентных чисел, Manrope — для текста и интерфейса. Оба шрифта распространяются по SIL Open Font License и поставляются локально через Fontsource. Пользовательские фото, видео и схема базы являются исходными материалами проекта.
